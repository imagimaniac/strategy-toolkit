# strategy-toolkit

Config-driven strategy frameworks → Markdown/JSON/CSV. Built for strategy consultants.

## MVP (v0.1)
- Issue Tree (MECE)
- Weighted Decision Matrix (with sensitivity)
- Strategy Canvas (Blue Ocean)

## Quick start
```bash
cd /Users/impro/projects/strategy-toolkit
pip install -r requirements.txt
streamlit run app.py
```

## Usage
1. Select a module.
2. Upload or paste YAML (or load an example).
3. Review live Markdown preview.
4. Export md/json/csv (one click bundle).

## Principles
- Config-first: YAML defines the artifact.
- Human-readable exports: Markdown prioritized for memos.
- Minimal deps, forkable.
